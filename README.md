# Website Profil Organisasi Kampus

Projek ini merupakan tugas praktikum Desain Web berupa website statis profil
Himpunan Mahasiswa Informatika yang dibangun menggunakan HTML murni.

Website menampilkan informasi mengenai profil organisasi, program kegiatan,
alur pendaftaran anggota, serta tautan media sosial dan email.

# Fitur

1. Halaman utama menampilkan nama organisasi Himpunan Mahasiswa Informatika,
   deskripsi singkat mengenai organisasi, serta gambar gedung kampus dan
   kegiatan organisasi.

2. Navigasi dibuat menggunakan berbagai jenis hyperlink, yaitu anchor internal
   (#id) untuk berpindah ke bagian Profil, Program, dan Pendaftaran, link
   eksternal ke Instagram, serta link email menggunakan mailto.

3. Bagian program organisasi menampilkan beberapa jenis kegiatan menggunakan
   unordered list, ordered list, dan description list.

4. Bagian alur pendaftaran menampilkan tahapan pendaftaran anggota organisasi
   menggunakan ordered list.

5. Penerapan atribut HTML seperti src, href, alt, width, id, dan target.
